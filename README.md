# Szímő kampányoldal

Mobilra optimalizált, kétnyelvű kampányoldal Bombicz Katalin számára.

## Gyors beállítás

1. A valódi portrét másold az `assets` mappába `portrait.jpg` néven.
2. Az elérhetőségek már be vannak állítva az `index.html` fájlban.
3. A `script.js` fájlban cseréld ki ezt:
   `https://formspree.io/f/SAJAT_AZONOSITO`
   a Formspree saját végpontjára.
4. Töltsd fel a teljes mappát GitHub Pagesre.

## Fájlok

- `index.html` – az oldal szerkezete
- `style.css` – teljes megjelenés
- `script.js` – nyelvváltás, fade és Formspree
- `translations.js` – magyar és szlovák szövegek
- `assets/portrait-placeholder.svg` – ideiglenes portrékép
- `assets/footer-line.svg` – alsó díszvonal
- `privacy.html` – adatkezelési placeholder
- `imprint.html` – impresszum placeholder

## Nyelvváltás

A nyelvváltó gomb csúszó kijelölést és finom fade animációt használ.
